# GDP Line Plot Project

## 📊 Project Description

This project reads GDP data from a CSV file and creates a line plot to visualize GDP trends over different years.

## 🛠️ Technologies Used

- Python
- CSV
- Matplotlib
- Pytest

## 📁 Project Files

- `main.py` – Contains the main functions for reading and processing GDP data and creating the plot.
- `test.py` – Contains test cases for the project functions.
- `gdp.csv` – Dataset containing GDP information.

## ⚙️ Functions Used

- `read_csv_as_nested_dict()`
- `build_plot_values()`
- `build_plot_dict()`
- `style()`

## 📈 Output

The project generates a line graph showing how GDP changes over time for selected countries.
